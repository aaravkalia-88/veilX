    01 / Private originals never enter the protected AI path.

    Compose and restore in an extension-owned panel. Only redacted text enters the provider’s page. Provider-owned editors can observe raw typing; in-page convenience mode has a weaker boundary. Normal login still identifies the account to its provider.

    02 / Active cookies stay in Chrome.

    The session section shows local metadata; pasted secrets are blocked, and reviewed browser rules can block known trackers. This is not an encrypted cookie vault or a promise to prevent every leak. Credential placeholders are never restored.

    03 / TinyFish investigates public policy.

    Backend-held key → live public-page navigation → evidence → validation → cache → risk badge and redaction mode. All boxes and module paths describe the proposed app; this document runs no live audit.
